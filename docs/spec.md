# LR-Flashcards 仕様書

このアプリの「現状の事実」をまとめたもの。設計判断や運用ルールを変更する時の参照元。

---

## 1. 概要

Language Reactor (LR) で保存した単語・フレーズを、iPhone のホーム画面アプリ風に復習する Web アプリ。

- 公開URL: https://mkttkmt.github.io/lr-flashcards/
- 配信: GitHub Pages
- 自動化: GitHub Actions
- データ更新: 手動（LR からエクスポートした JSON を `data/items.json` に上書き push）

---

## 2. データ取り込み

### 抽出ルール

LR からエクスポートした JSON (`learningStage: "LEARNING"` フィルタ済み) を入力とする。

**単語 (`itemType: "WORD"`)**
- `freqRank` を持つもののみ対象
- `freqRank` 昇順（小さい＝頻出）でソート
- 単語（lowercase）で重複排除（同単語が複数あれば freqRank 小さい方を残す）
- **上位 100 語** を抽出

**フレーズ (`itemType: "PHRASE"`)**
- `timeCreated_ms` 昇順（古い順）でソート
- フレーズ全文（subtitles[1] の lowercase）で重複排除
- **上位 20 件** を抽出

合計、最大 120 枚のカードがアプリに搭載される。

### JSON フィールドのマッピング

| カード項目 | 単語のソース | フレーズのソース |
|---|---|---|
| 表示テキスト | `word.text` | `context.phrase.subtitles[1]` |
| 訳 | `wordTranslationsArr` | `hTranslations[1]` → なければ `mTranslations[1]` |
| 品詞 | `subtitleTokens` から該当 token の `pos` を導出 | 固定値 `"phrase"` |
| freqRank | `freqRank` | `freqRank`（信頼性は低い、参考程度） |
| 英語例文 | `subtitles[0,1,2]` を結合 | 表示なし |
| 日本語例文 | `hTranslations` → `mTranslations` を結合 | 表示なし |
| 機械翻訳フラグ | `baseTrack.langCode_G == "ja"` | 常に false |
| 出典 | `reference.diocoDocName` | 同左 |
| ストレージキー | `word.text.toLowerCase()` | `subtitles[1].toLowerCase()` |

### 機械翻訳判定

`context.phrase.reference.tm.baseTrack.langCode_G == "ja"` の場合、英語例文は機械翻訳由来として**非表示**にする。日本語例文は表示する（元発言を理解するため）。

## 3. カード表示

### 表面
- freqRank ラベル（超頻出 / 頻出 / 標準 / やや稀 / 稀）と「順位 ◯」の数字
- 記憶バッジ（未学習 / 学習中 / 苦手 / 習得）
- メイン表示（単語 or フレーズ）
- 品詞
- 🔊 ボタン（発音）

### 裏面（タップで表示）
- 上記すべて
- 訳
- 英語例文（あれば、🔊ボタン付き）
- 日本語例文
- 出典

### freqRank ラベルの判定
| freqRank | ラベル |
|---|---|
| ~300 | 超頻出 |
| ~600 | 頻出 |
| ~900 | 標準 |
| ~1700 | やや稀 |
| 1701~ | 稀 |

### メイン表示の文字サイズ

表示テキストの長さに応じて自動調整：
| 文字数 | 表面 | 裏面 |
|---|---|---|
| ~20 | 36px | 28px |
| 21-40 | 24px | 20px |
| 41-70 | 20px | 17px |
| 71~ | 16px | 14px |

## 4. 学習ロジック

### 出題

「やめる」を押すまで無限にカードが続く（無限ストリーム）。同じカードの連続出題は回避する。

### 評価ボタン

- **忘れた** (level 0)
- **怪しい** (level 1)
- **覚えた** (level 2)

### 重み（出題確率）

重みは直近の評価で決まる：

| 状態 | 重み |
|---|---|
| 未学習（一度も評価していない） | 1.0 |
| 直近「忘れた」 | 1.5 |
| 直近「怪しい」 | 1.5 |
| 直近「覚えた」 | 0.5 |

抽選は重みの比例で行う。例えば未学習が10枚、直近「覚えた」が10枚なら、未学習の方が2倍出やすい。

---

## 5. バッジ判定

カード表示と単語一覧で見えるバッジ。重み計算とは独立した「目印」として機能する。

判定優先順：

1. **習得**（緑✓）: 覚えたが 5 回以上
2. **苦手**（赤✓）: 忘れた + 怪しい の合計が 5 回以上
3. **学習中**: 何かしら評価あり
4. **未学習**: 評価ゼロ

---

## 6. 評価データの永続化

ブラウザの `localStorage` に保存。

- キー名: `lr_word_memory_v2`
- カードキー: 単語は `word.text.toLowerCase()`、フレーズは `subtitles[1].toLowerCase()`
- 値:
  ```js
  {
    ok: 0,         // 覚えた回数
    maybe: 0,      // 怪しい回数
    no: 0,         // 忘れた回数
    lastLevel: 0/1/2/undefined,  // 直近の評価
    last: timestamp,  // 最終評価日時
    weight: 数値    // ※過去のロジック残骸、現在は未使用
  }
  ```

### クリーンアップ

アプリ起動時に、新 JSON に含まれていないカードキーの履歴を自動削除。

→ LR で「既知としてマーク」 → 次回 JSON エクスポート → アプリから単語が消える → 履歴もクリーンアップされる、という流れに対応。

## 7. 学習時間トラッキング

セッション（▶スタート〜やめる）の実時間を計測。

- 単位: 分（整数）
- バックグラウンド時（タブ切替、アプリ閉じ）は計測一時停止、復帰で再開
- 保存先: `localStorage` の `lr_study_time_v1`
- 日付の境目: 深夜0時（端末タイムゾーン）
- 保持期間: 過去 90 日。それ以前は自動削除

### 表示
- スタート画面: 「今日の学習時間 ◯分」+ 過去7日の縦棒グラフ（自動スケール、今日は強調）
- セッション終了画面: 「今回 ◯分 / 今日累計 ◯分」

---

## 8. 単語一覧画面

「📋 単語一覧を見る」リンクから遷移。

- 全カードを表示（最大 120 件）
- 並び順: build.py で抽出した順（単語 freqRank 順 → フレーズ古い順）
- 各行: 左にマーク（緑✓ or 赤✓）+ 単語/フレーズ + 右に「忘れた◯ / 怪しい◯ / 覚えた◯」
- フレーズの表示: 先頭 5 単語 + 「…」で省略
- マーク：習得 = 緑✓、苦手 = 赤✓、それ以外なし

## 9. 音声

Web Speech API による読み上げ。

### 音声の優先順位
1. Ava
2. Allison
3. Karen
4. Samantha
5. en-US の任意の音声

iPhone で Ava を使うには：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語 → Ava をダウンロード。

### 読み上げ速度
- 単語: 0.95
- 英語例文 / フレーズ: 0.9

### 自動読み上げ
- カード表示時に表面の単語/フレーズを自動読み上げ
- 裏返した時に英語例文を自動読み上げ（フレーズは例文なしなので何もしない）
- 「自動読み上げ」トグルで OFF 可

## 11. 更新フロー（運用）

### 毎週の作業
1. LR から JSON エクスポート（学習段階：学習中、フォーマット：JSON）
2. ダウンロードしたファイルを `data/items.json` にリネームしてローカルリポジトリに上書きコピー
3. GitHub Desktop で commit & push
4. GitHub Actions が自動でビルド・デプロイ（1〜2分）
5. iPhone でアプリリロード

### LR 側のメンテナンス
- アプリの「単語一覧」を見て、習得（緑✓）した単語は LR で「既知としてマーク」に変更
- 苦手（赤✓）で「問題自体に違和感」を感じた単語は LR で削除も検討
- これらを反映したJSON を次回エクスポートすれば、自然とアプリのデータが入れ替わる

## 13. 既知の制約 / 留意点

- **フレーズの freqRank は信頼性が低い**：LR がフレーズ内のどの単語の頻度を採用してるか不明。同じイディオムでもランクがばらつく可能性がある
- **フレーズの保存範囲は不明**：JSON にはフレーズ内のどこを保存したかの情報がない。文全体を1つのカードとして扱う
- **localStorage 依存**：ブラウザのストレージをクリアすると評価データ・学習時間が消える
- **同期はLR→アプリのみ**：アプリで「覚えた」と判定しても LR には反映されない。手動で LR を更新する必要あり
- **iOS Safari の音声制限**：初回タップで音声をアンロックする必要あり（▶スタート押下時）
